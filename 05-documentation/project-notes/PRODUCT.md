# SIF Sentinel

**Platform:** desktop-first responsive web dashboard for a SIH demonstration.  
**Users:** HSE officers, supervisors, safety analysts and operations leaders.  
**Jobs:** triage narratives, surface potential SIF precursors, find similar reports, prioritise review, and monitor recurring site/activity risk.  
**Positioning:** a human-reviewed safety-intelligence workbench, not a chatbot or a safety procedure.  
**Evidence:** no Oil India operational records are preloaded. The included database contains a clearly marked public reference corpus; user-submitted/imported records retain their stored provenance.  
**Honest claims:** transparent demo scoring, rule-based extraction, local similarity when available, and prototype analytics. It does not claim Oil India data, approval, or externally validated model performance.  
**Prototype constraints:** no paid service, account, or transformer download is required; SQLite is local and ships with public reference data only.
