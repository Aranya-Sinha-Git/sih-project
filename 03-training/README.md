# Training workstream

`ml/` contains baseline training scripts and the isolated `sif_v0_1` model workspace, including candidate creation, labeling data, evaluation reports, artifacts, and tests.

Use `ml/sif_v0_1/README.md` for commands. Its scripts read the validation sources from `../04-data/validation-datasets/` and reuse the Python environment in `../01-app/backend/`.
