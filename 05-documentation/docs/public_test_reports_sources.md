# Public test reports

`01-app/backend/data/public_test_reports.csv` is a small test fixture, not Oil India data and not a representative dataset. Its narratives are concise paraphrases of public official sources, except `PUBLIC-HSE-002`, which is explicitly marked as a guidance-derived positive-control scenario.

- CSB’s PBF Energy Martinez report documents a pressurised flammable-hydrocarbon release after the wrong flange was opened during turnaround maintenance.
- CSB’s PEMEX Deer Park investigation documents a hydrogen-sulfide release following wrong-equipment selection during blind installation.
- DOE operating-experience summaries document an improperly verified lockout/tagout and a zero-energy check that found an energised switch before exposure.
- UK HSE describes an electrical shock caused by inadequate isolation and provides the safe-isolation principles used for the positive-control fixture.

Each original source URL is retained per row in the CSV. Do not use the test labels as a professional SIF determination; they are only expected test outcomes for this prototype.
