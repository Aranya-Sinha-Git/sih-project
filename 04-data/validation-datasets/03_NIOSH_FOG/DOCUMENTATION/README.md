# NIOSH FOG documentation

FOG is an industry-specific fatality surveillance subset for U.S. oil and gas extraction workers, covering 2014-2019 in the published system description. NIOSH states it is not a complete census. The official Worker Health Charts and CDC Stacks links are cited in `00_MANIFEST/CITATIONS.md`; direct file endpoints returned HTTP 403 in this environment, so no raw row-level FOG file is claimed here.
